# python-cleaner
Python automatic file cleaner for the downloads folder

## Requirements
* See suported operating systems below
* Python 3.14.7 or above
* The supported directories must be in the user directory and have the specific naming (see supported directories below)

## Useage
Navigate to python-cleaner/code and run the following in the terminal:
```
python Cleaner.py
```

## Supported operating systems
* Linux
* MacOS
* Windows 10
* Windows 11

## Supported Directories
* Downloads
* Documents
* Pictures
* Music
